# LENDAS — regras do projeto para o Claude

- Tile do mundo: **48 × 48 px**.
- Pixel art sem blur: nada de suavização bilinear nem antialias. Escala sempre com NEAREST ou BOX.
- Não desenhar arte por código quando já existir PNG do projeto ou um PNG aprovado.
- Antes de alterar qualquer arquivo, fazer backup em `art-pro/backups/`.
- `art/source/` guarda os originais e é **intocável**: trabalhar só em cópias.
